# Personal Portfolio

## How to Run

### Option 1: The Simplest Way
Go to the **`d:\Projects\portfolio`** folder and simply double-click the **`index.html`** file. It will open in your default web browser.

### Option 2: Using VS Code (Live Server)
1. If you have the **Live Server** extension installed in VS Code:
2. Right-click on `index.html`.
3. Select **"Open with Live Server"**.

### Option 3: Using the Terminal (Node.js or Python)
If you prefer a command-line approach, you can start a local server:

**Using Python:**
```powershell
# Run this in the portfolio directory
python -m http.server
```
Then open `http://localhost:8000` in your browser.

**Using Node.js:**
```powershell
# Run this in the portfolio directory
npx serve
```

## Project Structure
- **`index.html`**: Contains the content and layout.
- **`style.css`**: Handles the visual styling and animations.
- **`script.js`**: Manages the mobile menu and scroll animations.
